---
title: Windows Installation
description: How to download and install Hosila PMS or Hosila IMS on your reception or store Windows computer.
---

Both **Hosila PMS** and **Hosila IMS** install directly on Windows 10 and Windows 11 computers from the [Hosila Download Centre](/downloads).

## 1. Which Computer Should You Install On?

| Product | Where to Install | How Your Team Uses It |
| --- | --- | --- |
| **Hosila PMS** | Install **once** on your main Reception Windows computer. | Other reception desks, hotel restaurant/bar tablets, and manager offices connect over your property Wi-Fi using any web browser. |
| **Hosila IMS** | Install directly on your Central Store or Inventory Windows computer. | Storekeepers open Hosila IMS right on that computer—works completely offline. |

## 2. Running the Setup Installer

1. Download the installer for **Hosila PMS** or **Hosila IMS** from the [Download Centre](/downloads).
2. Double-click the downloaded setup file and follow the on-screen prompts.
3. Wait a few seconds for the shortcut to appear on your desktop.

## 3. First-Time Welcome Wizard

- **Hosila PMS:** Opens cleanly in your browser. Follow the **3-step Hotel Setup Wizard** to enter your property name, room categories, room numbers, and nightly rates.
- **Hosila IMS:** Opens directly as a desktop application. Follow the **4-step Store Setup Wizard** to add your store name, admin login, departments (Kitchen, Bar, Housekeeping), and opening items.

Both applications include a **14-day full-access trial** so your team can test everyday workflows before activating a license.
